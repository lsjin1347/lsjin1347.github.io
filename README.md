# Academic Research Lab Website

A lightweight, responsive static website intended for deployment at
`https://lsjin1347.github.io/` with GitHub Pages.

## Structure

- `index.html` — home page
- `members/` — professor, students, and researchers
- `research/` — research overview
- `publications/` — international and domestic publications
- `activities/` — courses, conferences, invited talks, and peer review
- `news/` — news and gallery
- `links/` — useful links
- `assets/css/` and `assets/js/` — shared styles and navigation behavior
- `assets/images/` — organized image folders for future content

No build step is required. Open `index.html` locally or publish the repository
through GitHub Pages.
